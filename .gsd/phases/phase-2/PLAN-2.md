# Phase 2, Task 2: Polish Portfolio Cards & Add Visual Excellence

## Goal
Use the frontend-design skill to make portfolio cards visually impressive — this section IS the proof of capability.

## Context
- Data infrastructure is in place (from Task 1)
- Portfolio cards need to be portfolio-worthy themselves
- Must use frontend-design skill per CLAUDE.md requirements
- Cards should demonstrate: browser mockup, hover interactions, smooth animations

## Actions

### Step 1: Activate frontend-design Skill
- Use the frontend-design skill for all visual work in this task
- Direction: Warm, inviting, professional. Watercolor-inspired. Not corporate/cold.

### Step 2: Enhance Project Card Design
- **Browser mockup frame**: Chrome-style window frame around screenshot (dots, address bar)
- **Hover effect**: Subtle scale + shadow lift, screenshot scrolls or reveals mobile view
- **Tech tag badges**: Pill-shaped, styled consistently with site's color palette
- **Type badge**: Small colored label (e.g., "אתר תדמית" in sage/orange tag)
- **CTA button**: "צפה באתר →" with arrow, hover animation
- **RTL**: All text right-aligned, arrow direction correct for RTL

### Step 3: Add Section Decorations
- Subtle background decorations consistent with other sections
- Floating elements or organic shapes (watercolor feel)
- Smooth scroll-triggered entrance animations

### Step 4: Verify Visual Quality
- Desktop: Card centered, ample whitespace, readable
- Mobile: Full-width, stacked layout, touch-friendly
- Hover effects smooth (60fps)
- RTL correct — no LTR artifacts
- Run `npm run build` — clean
