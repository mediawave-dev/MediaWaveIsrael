# Contract: the opener's lens (DECISIONS #64)

The file draws; the page moves. Rive renders the lens (barrel, focus ring, nine iris blades, the depth and the glass); `src/look/parts/Lens.tsx` drives the iris through these names. Generated by `build-lens.mjs` (`npm run rive:lens`) from `src/look/parts/lens-geometry.js`, which the page uses too, so the static frames and the live file are one drawing.

## View model (page to Rive, every frame while the iris moves)

| name | meaning |
|---|---|
| `v0x`, `v0y` | blade 0's corner on the opening (lens-centred units) |
| `e0x`, `e0y` | the far end of blade 0's edge, under the barrel |
| `e1x`, `e1y` | the far end of the next blade's edge (blade 0's face is the triangle e0, v0, e1) |
| `g0x`, `g0y`, `g1x`, `g1y` | blade 0's light: from the middle of its edge (lit) to e1 (shade) |
| `focus` | the barrel's turn in radians (focus ring and knurling) |

Blades 1 to 8 are blade 0 turned by 40 degrees each, so these numbers move all nine.

## States

| state | aperture | who |
|---|---|---|
| first visit (`html.hero-iris` before the first paint) | paints closed (`lens-closed.svg`), holds 0.28 s, snaps fully open, stops down to rest | `index.html`, `Lens.tsx` |
| rest | 0.72 (`lens-rest.svg` is the same pose) | |
| pointer over the lens | 0.92, the blades turn a little toward the pointer | `Lens.tsx` |
| click or tap on the lens | a shutter: shut and open again (150 ms) | `Lens.tsx` |
| scroll | opens toward 1 as the hero leaves; the box scales up (GSAP, one transform) | `Lens.tsx`, `HeroLens.tsx` |
| CALM | starts at rest, no opening; pointer, shutter and scroll stay (the visitor's own actions) | |
| REDUCE, prerender, no JS, Rive late (4.5 s) | `lens-rest.svg` | CSS |

The film inside is `LENS_FILM` (`HeroMedia.tsx`): Pexels 5585952 (RDNE Stock project, Pexels licence), cut square around the laptop and the hand, looped forward and back (7.6 s): 720 px 740 KB, phones 600 px 396 KB, posters 46 KB and 34 KB.
