# Rive motion brief: MediaWave

## The piece

**Contact companion** (`design/rive/companion/`). The one Rive piece on the site; the buttons stayed CSS/JS (DECISIONS #50, button families per look), so the runtime ships only where it earns its bytes: a character driven by real form states.

- **Sentence only this brand could say:** whoever writes to us gets the laptop that builds their site, and their message becomes the mark.
- **Where:** top of the contact form, start side (right in RTL), 232 px desktop, 176 px phone. On the KM stage (black, ink #F5F5F7, secondary #A1A1A6); the same file works on the M void.
- **States (the form's real lifecycle):** idle, typing (a field has focus, lines follow the characters typed), loading (the request is out), sent, error. See `companion/CONTRACT.md`.
- **Personality:** calm, precise, attentive. Decisive ease-out, no overshoot, no elastic, nothing loops at rest.
- **First-instinct check:** not a blob mascot (the hero's own laptop), no eyes, no confetti or spinner ring (the loading wait is the brand's horizon sloshing), no text in the canvas (the lines are abstract words; the form's status and alert messages carry the meaning), no loop that never rests (blink 4 cycles, slosh only while the network is out).
- **Budget:** subtle intensity, 60 KB file budget (actual 7.2 KB). Runtime canvas-lite: 49.8 KB gzip JS + 365 KB gzip wasm, loaded only after load + idle + near the form.
- **Sketch stage:** skipped on purpose. Nati chose "a Rive character" at STOP 1 with questions allowed only at the stops; the concept was decided from the brief (REDESIGN-PROMPT §5, §8.6) and is judged from the rendered states instead (shots below).

## How to extend

Edit the numbers in `companion/build-scene.mjs` (geometry `G`, colours `COL`, poses `REST`/`FOLDED`, the animations), then `npm run rive:companion`. It regenerates `cli/scene.rml`, `src/look/parts/companion-rest.svg` and `src/look/parts/companion.riv` together, so the CSS rest pose can never drift from the Rive idle pose. Re-run the probe:

```
node C:/Users/User/.claude/skills/rive-studio/scripts/rive-probe.mjs src/look/parts/companion.riv --contract design/rive/companion/CONTRACT.md --shots design/rive/companion/shots/probe --renderer canvas-lite --size 660x432
```

Names in the contract are an API: renaming `status`, `progress`, `keystroke` or `prefersReducedMotion` needs the matching change in `Companion.tsx`.
