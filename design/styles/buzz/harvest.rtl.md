# קציר סגנון: Buzz (buzz.xyz)

נקרא ב-21.10.2026 לצורך שחזור **הסגנון** (לא הנכסים) באתר סטודיו בעברית.
הקוד נקרא כטקסט בלבד: `G:/tmp/harvest/buzz/index.html`, `main.js` (‏434KB, React + Vite + framer-motion), `a.css` ו-`sites.css` (הורדו ב-curl), וצ'אנק הנקודות `dotgrid.js`.
שום JS שלהם לא הורץ מחוץ לביקור בדפדפן, ושום תמונה, וידאו או אווטאר שלהם לא נשמרו.
סטטוס: **מאומת** = נראה בקוד או בפריים; **הוסק** = שוחזר מקוד מכווץ; **מדידה** = נמדד בצילום.
מקור "main.js @N" = היסט התו בקובץ.

הערת סביבה: המחשב היה עמוס מאוד, וה-screencast תפס רק 2-4 פריימים בשנייה בפועל.
לכן תזמוני הפתיחה בטבלאות לקוחים מהקוד, והפריימים משמשים רק כעדות למראה.
עוד הערה: סרט הטלפון צולם עם UA של iPhone Safari, והאתר מזהה Safari ומחליף את פילטר ה-SVG של הלוגו בתמונת PNG מוכנה (`_l()` ב-`main.js`); באנדרואיד/כרום יוצג הפילטר החי.

## 2. הדבורים (הרגע שבעל הפרויקט אהב)

**מה הן:** אלמנטי DOM, לא קנבס.
כל דבורה היא `span` מוחלט ובתוכו `svg.bee-sprite` ‏`viewBox 0 0 466 309` עם `path` יחיד (‏fill-rule evenodd) בצורת הלוגו: שני חצאי עיגול ככנפיים (‏r 91.7), גוף מלבן מעוגל (‏rx 34), שתי עיניים ושני חריצים שהם חורים.
גודל בסיס 46x31px כפול `sizeScale .58` = כ-27x18px; צבע לפי hash של האינדקס מתוך הפלטה.
התנועה: `requestAnimationFrame` אחד לכל קבוצה, `transform: translate(x,y) rotate(a) scale(.58)`, ‏`will-change:transform`.
מקור: הפונקציות `wt` (קומפוננטה), `ug` (מיקומי בית), `hg` (צעד סימולציה) ב-`main.js @248500-256700`.

**כמה ואיפה:**

|---|---|---|---|---|
| hero, אחורית | 44 | 22 | `#D7E7F5`, `#DBFA52` | ‏z 0, מתחת ללוגו |

**מודל הטיסה (צעד אחד, `dt` מוגבל ל-0.05s):**

| כוח | נוסחה וקבועים |
|---|---|
| נדידת כיוון | `heading += (sin(t*(.27+.4s)+2πs) + .6*sin(t*(.13+.11s)+7s)) * 1.15 * dt` (‏s = seed לכל דבורה) |
| התחמקות מקצוות | בתוך 110px מהקצה: הכיוון מסתובב פנימה בעוצמה `3.2 * strength * dt` |
| מהירות שיוט | `58px/s * (1 + .32*sin(t*(.42+.28s)+2πs))`, מינימום `58*.46` |
| זינוק (dart) | פאזה `w = frac(t*(.24+.2s) + 5.37s)`; כש-`w < .18` (‏18% מהמחזור, מחזור 2.3-4.2s): ‏`k = sin(π*w/.18)`, תוספת מהירות `רוחב_המסך * 1.1 * k` לשנייה, ותגובתיות `2.4 + 11k`. זה מה שנראה כ"עפות לכל מיני מקומות": כל דבורה, בתורה, חוצה חצי מסך בהבזק |
| התפזרות | בתוך 66px אחת מהשנייה: דחיפה `1300*(1-d/66)/d` |
| הסמן | בתוך 380px: דחיפה `1600*(1-d/380)/d`; רק `pointer:fine` ובלי reduced-motion |
| בית | קפיץ לנקודת בית `0.18 + 0.9*outside`; הבתים מפוזרים ברצף "plastic number" (‏1.3247) בתוך שוליים 12%/14%, כך שהפיזור שווה ולא אקראי |
| קירות | בתוך 110px: ‏`900*(1-d/110)` פנימה; ריסון `0.97` לכל פריים; פגיעה בקיר = היפוך מהירות `x -0.5` |
| סיבוב | `rotate = heading + 90°`; כשהמהירות מעל 6, הזווית מתקרבת לכיוון התנועה ב-18% לפריים |
| כניסה | כל דבורה מתחילה על אליפסה מחוץ למסך (רדיוס `0.7*גודל + bleed + 46`) ונמזגת לסימולציה עם `1-(1-p)^3` לאורך 1050ms |
| כנפיים | יש ב-CSS אנימציית נפנוף (‏5.2s, שלושה נפנופים מהירים בין 62% ל-88%, ‏`translate 44px scaleX .82`, השהיה לפי hash), אבל היא מכוונת ל-`.bee-wing` שלא קיים בספרייט, כך שבפועל אין נפנוף; ה"רטט" שרואים הוא הסיבוב והזינוקים |
| reduced motion | מיקומים סטטיים, בלי לולאה ובלי דחיפת סמן |
