## מלכודות שכבר עלו
- בלוק inline-block הוא מועמד LCP נפרד; חלק בפתיחה שדוהה מ-0 מאחר את ה-LCP. ספרות בשורה עברית מושכות את קובץ הלטינית של Noto (שניהם ב-preload).
- WebKit של Playwright חוסם את הפורט 4190, ואין בו WebAudio ב-Windows (בספארי אמיתי יש). Chromium של Playwright: להצביע על `ms-playwright/chromium-1217/chrome-win64/chrome.exe`. Playwright מותקן ב-`G:\tmp\pw` (‏`xb.mjs` בודק שישה דפדפנים).
- Windows לא מבחין באותיות גדולות וקטנות בשמות קבצים: קובץ נתונים וקומפוננטה עם אותו שם שוברים את tsc ואת שרת הפיתוח.
- סקריפטי Python ארוכים: לכתוב לקובץ ולהריץ (heredoc ארוך נשבר ב-Git Bash). ‏`MSYS_NO_PATHCONV=1` לנתיבים עם "/".
- Lighthouse מקומי רק מול שרת שדוחס ב-brotli (סקריפט בשם `serve-br.mjs` בתיקיית ה-scratchpad של הסשן הקודם, או לכתוב חדש), ולהריץ אותו כשהמחשב שקט.
- אסור להריץ prerender פעמיים על אותו dist (ה-preload מוכפל): תמיד `npm run build` מלא.
